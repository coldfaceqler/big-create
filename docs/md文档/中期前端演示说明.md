# DYOLL：中期前端演示

项目名称为「DYOLL：结合大语言模型的保险合同分析软件」。当前交付是可交互的前端原型，页面中的条款、风险等级、批注和核实事项全部为虚构的预设样例，不代表真实合同的分析结果。

## 本地运行

Windows 下可直接双击项目根目录的「启动演示.cmd」。脚本会在缺少依赖时安装依赖，再启动本地页面并打开浏览器。依赖安装成功后，再次演示无需重复安装。保留启动窗口；结束后按 Ctrl+C 停止服务。

需要支持 Vite 7 的 Node.js（本次使用 Node.js 24）。在项目根目录运行：

```powershell
npm install
npm run dev
```

打开终端显示的地址，默认是 `http://127.0.0.1:5173/`。再次演示时依赖已安装，只需运行 `npm run dev`。保留终端窗口；结束后按 Ctrl+C 停止服务。

构建检查：

```powershell
npm run build
```

构建包含 TypeScript 检查，结果输出到 `dist/`。本轮界面不使用远程字体、图片或模型服务；安装依赖后，本地演示不依赖外部网络。

## 中期展示顺序

1. 首页点击「打开示例合同」，说明正在加载预设演示数据。
2. 查看第一条等待期批注，介绍「原文、情形、条件、给付、关注原因」。
3. 点击手术条件批注，右侧原文同步定位并高亮。窄屏下点击「查看原文与上下文」打开弹窗。
4. 切换「未知」筛选，说明缺少基准不等于低风险；展开后能看到「需复核」。
5. 输入关键词搜索，再切换原文索引，浏览未生成批注的条款。
6. 展示列表末尾的三条待核实事项。
7. 回首页，展开「演示其他处理情况」，演示扫描件失败或非重疾险材料只保留索引。

可以这样介绍当前进度：前端已经实现合同选择、批注阅读和原文回溯交互；批注字段与项目方案一致，真实解析和规则输出将在后续接入。

## 文件选择的真实行为

支持本地选取或拖入单个 PDF（演示限制为 20 MB）。仅检查扩展名、大小和 PDF 文件头，不读取合同正文，不持久保存文件，不发送上传请求。点击「继续阅读」会提示解析服务尚未接入，不会把样例批注当成该文件的分析结果。

扫描件和材料性质的按钮是独立演示情景，不是文件检测能力。

## 代码入口

- `src/App.vue`：页面状态、文件选择、演示流程和阅读交互。
- `src/styles.css`：视觉样式与窄屏布局。
- `src/types.ts`：与整合方案第 11 节一致的批注字段。
- `src/data/demo.ts`：虚构示例条款、批注、展示标题和待核实事项。
- `src/components/AnnotationCard.vue`：批注展示。
- `src/components/SourceExcerpt.vue`：原文段落与高亮。

## 后续对接

保留既有批注字段，另与后端约定上传、处理状态、失败原因、全文条款索引和上下文的返回格式。用真实接口替换演示场景载入逻辑；得到真实成功响应后才进入分析结果页。产品需确认理想批注和风险用语，算法需提供可回溯原句及覆盖情况。
