# 任务看板

这是唯一的开工清单。群里说了但没写进这张表的事，视为没排期。改这张表用单独的小分支，例如 `board/week-1`，走 Pull Request。

状态只用四个词：**未开始**、**进行中**、**评审中**、**已合并**。一个人不要同时有两行「进行中」。

前置是「无」的可以开工。前置写着另一行的，要等那一行变成「已合并」。第二阶段的问答、两份合同对比、理赔材料清单先不要加进行。
