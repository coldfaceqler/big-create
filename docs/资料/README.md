# docs/资料 分类说明

本文件夹存放项目用到的全部外部资料，按用途分成 5 个子目录，不再堆在同一个目录里。

## 目录结构一览

| 目录 | 放什么 | 谁最常用 | 什么时候用 |
|------|--------|----------|------------|
| `条款库/` | 8 份重疾险条款 PDF + 下载清单 | 全组 | 评测集核心语料，切分、金标、规则都以它为准 |
| `规范与监管/` | 2020 版疾病定义使用规范 | 产品 / 算法 | 第二层"定义偏离"的硬基准 |
| `司法案例/` | 法院白皮书、网页引用核心信息汇编 | 产品 | 定风险句、判"是不是隐性限制"的依据 |
| `学术论文/` | 6 篇技术方法论文 | 算法 | 切分、检索、评估方法的参考 |
| `行业数据/` | 赔付发生率报告 | 算法 | 第二层决定先比对哪种病 |

## 每个目录里具体有什么

### 条款库/（项目核心语料）

- 8 份重疾险条款 PDF，命名规则 `公司_产品名.pdf`：
  - 北京人寿_京康安护重大疾病保险_互联网专属
  - 国寿_康宁女性重大疾病保险_互联网专属
  - 恒安标准_瑞享福尊享版重大疾病保险_互联网
  - 平安_个人重大疾病保险2021A款_互联网版
  - 平安养老_关爱一生2024团体终身重大疾病保险
  - 太保_金生无忧少儿版重大疾病保险
  - 太保_钛强PAI团体重大疾病保险
  - 泰康_神奇宝贝2021款重大疾病保险
- `_下载清单.csv`：每份的**来源 URL、下载结果、文件大小**，核对来源看这里。
- 全部来自**保险公司官网公开披露页**，是文字版 PDF（能抽出文字，不是扫描件），不含投保人个人信息，无需脱敏。

### 规范与监管/

- `重大疾病保险的疾病定义使用规范（2020年修订版）.pdf`——**硬基准**。第二层"相对 2020 版规范多了哪些条件"就逐条对照它；里面是 28 种重度 + 3 种轻度的标准定义。

### 司法案例/

- `北京市西城区人民法院涉重疾险纠纷.pdf`——白皮书原文，第一层"优先标什么"的数字来源（284 件、六类抗辩）。
- `参考资料网页引用核心信息.pdf`（附 `.docx` 可编辑版）——把整合方案里 10 条网页引用（吴某案等 7 条案例 + 3 条数据/法规）的核心信息逐条提炼，离线可查。

### 学术论文/

6 篇技术方法论文，文件名带来源（arXiv 编号 / 会议）：
- `多模块健康险检索系统_SciReports.pdf`——条款级检索 + 质量评估的结构参考
- `ETIP_TOI-CNN_NAACL2019.pdf`——中文保单要素七分类标注
- `InsQABench_arxiv2501.10943.pdf`——中文保险问答基线
- `Non_LLM_Methods_for_RAG_Evaluation_vf.pdf`——用条款编号做确定性评估（本项目金标思路的来源）
- `OmniEval_EMNLP2025.pdf`——金融 RAG 评估，说明"检索生成不可直接当结论"
- `拉瓦尔_Quebec保险LLM基准_arxiv2603.07825.pdf`——RAG 会伤弱模型，风险警示

### 行业数据/

- `重庆监管局2023年度保险赔付报告.pdf`——发生率/赔付数据，只用于安排第二层先比对哪些病，不乘进风险分。

## 怎么新增条款（给工程）

1. 编辑 `tools/crawl_clauses.py`，在顶部的 `SEEDS` 列表加一行：`("公司_产品名", "PDF直链"),`
2. 只加**重疾险条款**直链；脚本会做相关性过滤（文件名或 URL 含「重大疾病 / 重疾 / 恶性肿瘤疾病 / 疾病保险」才下载），避免误爬无关文件。
3. 在仓库根目录执行：
   ```powershell
   python tools/crawl_clauses.py
   ```
4. 脚本下载到 `条款库/`，并重写 `_下载清单.csv`。

## 约定

- 条款 PDF 用 `公司_产品名.pdf` 命名，方便一眼认出来源。
- 只提交**公开披露的空白条款**；真实承保合同（含投保单、保单页、批单）即使脱敏也要先确认再决定是否进仓库。
- 文件的「本地路径」引用（比如整合方案第 12 节里 `docs/资料/...`）要跟着目录结构走，搬了文件就同步改引用。
